# LUMERIS Reel Maker — archived source stub

The standalone Reel Maker repository is no longer the active application source.

## Current application

The Reel + Post Maker is integrated into the main LUMERIS site at:

- Production URL: https://lumeris-mocha.vercel.app/studio
- Canonical repository: https://github.com/nas393/lumeris
- Source entry point: `studio.js` and the `/studio` route served by `api/page`

The active Vercel project is `lumeris`, not a separate `lumeris-reel-maker` project.

## Repository status

This repository contains only the initial source-recovery stub from the former standalone deployment. It is not a complete or deployable source of the current Studio application. Do not use it as the authoritative build source.

## Safety

Do not commit API keys, tokens, or other secrets. Configure required credentials as Vercel environment variables in the active LUMERIS project.
